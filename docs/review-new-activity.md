# Return to the activity that changed

Leave a command result open in task A, read task B, then come back to A. Desk returns to the same passage. When new native output arrived while you were away, choose **Read first new activity** to jump to its original item.

## Review a saved task

1. Open your saved task and wait for its native activity to load. The first visit establishes a review baseline for this browser.
2. Read the earlier command, answer or tool result you need. You can switch to another saved task and return to the same reading place.
3. When **New native activity since review** appears, choose **Read first new activity**. It opens the earliest recorded readable item update since your review. An older command with a new output segment can be that destination.
4. After reading the displayed updates, choose **Mark displayed updates reviewed**. Alternatively, choose **Latest output ↓** to deliberately follow and review the currently displayed frontier. Updates arriving afterwards remain available for your next review.
5. Reload in the same browser to keep the review boundary and your separate reading place. Reuse the same Codex home and Desk state directory when restarting the server.

Native task status and approvals remain visible independently. Review follows recorded parent-task material, so an output update and a task completion each retain their own meaning. When the original item is unavailable, the activity control displays its source status; reload or return to the original source before reviewing it.

Your current draft and paused follow-ups stay with their saved task throughout this reading workflow.

## Review changed work across projects

Choose **Changed saved work** in the sidebar to review **Changed and active** tasks grouped by project. A small dot identifies recorded native material newer than this browser's review boundary; the task's native status remains visible alongside it. Use **All saved work** to inspect tasks whose review baseline is still unknown.

Choose a task to return to its existing reading place, then use **Read first new activity** when ready. **Back to Changed work** returns to the same overview row and project/page scope, including after you review that task's updates. Changing the view, project, title filter or archive scope selects a new overview.
